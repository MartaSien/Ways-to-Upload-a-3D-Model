# Ways-to-Upload-a-3D-Model
## Description
Demonstration of simple and free ways to upload a 3D model and host it on [GitHub Pages](https://pages.github.com/), via `iframe`.

🌐 See the website online: https://martasien.github.io/Ways-to-Upload-a-3D-Model/

## List of 3D model hosting solutions

- Sketchup: https://www.sketchup.com/
- Sketchfab: https://sketchfab.com/
- Spline Design: https://spline.design/
- Shape Diver: https://shapediver.com/

## Contact

If you know of any other interesting ways to host a 3D model I would be grateful for an idea via [issues](https://github.com/MartaSien/Ways-to-Upload-a-3D-Model/issues). 🙂
